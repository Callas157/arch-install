# Callas OS visual pack

This branch contains the visual layout for the Callas OS installer.

- `logo/`: project icon used by Plasma and boot visuals
- `grub/`: centered GRUB theme
- `plymouth/callas/`: boot splash
- `login/`: KDE/SDDM background assets
- `lockscreen/`: lock-screen background assets
- `wallpapers/`: Callas OS wallpaper collection

The generated JPG/PNG artwork is added separately from the text theme files.
